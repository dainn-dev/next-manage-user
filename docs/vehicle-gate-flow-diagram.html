📝 Ghi Chú Chi Tiết Các Thành Phần

🔴 Edge Layer (Python)

  • Motion Gate (edge/edge/motion_gate.py): Phát hiện chuyển động để kích hoạt pipeline, giảm tải xử lý.
  • Vehicle Detector (edge/edge/vehicle_detector.py): YOLOv5 phát hiện xe trong khung hình.
  • Vehicle Tracker (edge/edge/vehicle_tracker.py): ByteTrack theo dõi xe qua các frame liên tiếp.
  • Plate Detector (edge/edge/plate_detector.py): YOLOv5 phát hiện vùng biển số.
  • OCR Engine (edge/edge/ocr_engine.py): Nhận dạng ký tự biển số từ ảnh đã crop.
  • Gate Client (edge/edge/gate_client.py): Gọi API backend để kiểm tra xe.
  • Plate Access Client (edge/edge/plate_access_client.py): Client chuyên biệt cho check-vehicle.
  • Barrier Controller (edge/edge/barrier_controller.py): Điều khiển rào chắn vật lý.
  • Camera Ingest Client (edge/edge/camera_ingest_client.py): Gửi event tracking/occupancy.
  • Event Queue (edge/edge/event_queue.py): Store-and-forward queue, gửi lại khi backend unreachable.
  • Snapshot Store (edge/edge/snapshot_store.py): Lưu ảnh chụp biển số.

🟢 Backend Services (Spring Boot)

  • GateEventDeduplicator: In-memory LRU cache (20K entries, TTL 10 phút), dedup theo eventId từ edge.
  • VehicleService.checkVehicleAccess(): Logic chính kiểm tra quyền vào cổng:
    • Normalize biển số → tra cứu DB → kiểm tra tenant registration (ADR-0604) → kiểm tra trạng thái.
    • Xe không tồn tại: tạo VehicleAccessRequest PENDING + WebSocket "chờ phê duyệt".
    • Xe tồn tại nhưng không đăng ký tenant: xử lý tương tự như không tồn tại.
    • Xe approved: cập nhật status (entered/exited), tạo VehicleLog, gửi WebSocket.
  • VehicleAccessRequestService.recordGateDetection(): Tạo PENDING request với dedup 5 phút (cùng plate + gate).
  • CameraIngestService: Idempotent insert theo (camera_id, event_id), lưu snapshot lên MinIO, publish outbox.
  • TrackingOccupancyIntegrationService: Nhận event VehicleDetected/PlateRecognized, ánh xạ tọa độ → parking slot, debounce trước khi cập nhật occupancy.
  • ParkingFeeService: Mở/đóng parking session, tính phí 5,000 VND/giờ (min 5,000), tích hợp SePay webhook.
  • WebSocketService: Gửi real-time events đến Dashboard (thông tin owner, vehicle, gate).
  • OutboxBus: Pattern outbox để đảm bảo event delivery.

🔑 Authentication

  • X-Gate-Key: API key cho edge gate (register, heartbeat, check vehicle).
  • X-Camera-Id + X-Camera-Key: API key cho từng camera (ingest events).
  • JWT Bearer Token: Cho frontend/admin users.
  • TenantContext: Multi-tenant isolation qua RLS (Row-Level Security) trong PostgreSQL.

🔄 Vehicle Status State Machine

  • approved → entered (khi check entry thành công)
  • entered → exited (khi check exit thành công)
  • exited → entered (cho phép entry lại)
  • rejected → cần admin phê duyệt → approved
